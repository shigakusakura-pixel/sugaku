📌 前提条件の確認（②で求めたグラフと各頂点）

直線 \(y = \frac{1}{2}x + 3\) と 直線 \(y = -x + 6\) の交点 A\((2, 4)\)、 \(x\) 軸交点 B\((-6, 0)\)、 C\((6, 0)\)

【例題】
上記の図において、点 A を通り \(\triangle\text{ABC}\) の面積を2等分する直線の式を求めよ。

1. 考え方のポイント

頂点 A を通り \(\triangle\text{ABC}\) の面積を2等分する場合、求める直線は対辺 BC の中点 M を通ればよい。

2. 座標の計算手順

【公式】中点の座標

2点 \((a, b)\) と \((c, d)\) の中点： \(\displaystyle \left( \frac{a+c}{2}, \; \frac{b+d}{2} \right)\)

・BC の中点 M ： \(\displaystyle \left( \frac{-6 + 6}{2}, \; \frac{0 + 0}{2} \right) = (0, 0)\) （原点）

3. 求める直線の式

点 A \((2, 4)\) と 中点 M \((0, 0)\) を通る直線 \(y = ax\) に代入する。

\[ 4 = 2a \implies a = 2 \]

答え： \(y = 2x\)
【類題】
直線 \(y = x + 4\) と直線 \(y = -2x + 10\) の交点を A とし、それぞれの直線と \(x\) 軸との交点を B, C とする。
点 A を通り、\(\triangle\text{ABC}\) の面積を2等分する直線の式を求めよ。

【解答】 \(y = 4x - 2\)

【解説】
1. 交点 \(\text{A}(2, 6)\)、\(\text{B}(-4, 0)\)、\(\text{C}(5, 0)\)
2. 辺 BC の中点 M \(\left( \frac{1}{2}, 0 \right)\)
3. A \((2, 6)\) と M \(\left( \frac{1}{2}, 0 \right)\) を通る直線の傾き \(a = \frac{6 - 0}{2 - \frac{1}{2}} = 4\)。
\(y = 4x + b\) に \((2, 6)\) を代入して \(b = -2\)。よって \(y = 4x - 2\)。
